# NeoPHI — PHI クライアントの Python による実装

PHI (v5y サーバ)のクライアントソフトウェアを、Python の標準ライブラリだけで
作り直したものです。仕様は [s7k/wphi](https://github.com/s7k/wphi) の
`docs/04-client-spec.md`(他の言語でクライアントを作る人のための仕様書)に
基づいています。コードはこの仕様書と wphi の実装を読みながら新規に書いた
もので、wphi のコードを写したものではありません(テストの正解データだけは
wphi の golden データを使っています。後述)。

## 動くもの

- **TUI クライアント**(`neophi.tui`):端末の画面に、状態・ログ・文字の
  地図・入力欄を出す。Philly と同じキー操作で移動や行動ができる。
- **GUI クライアント**(`neophi.gui`):Tkinter の窓に、BMP の絵の地図・
  ログ・リスト・入力欄を出す。地図のクリックでも移動できる。絵の元になる
  グラフィックスは、利用者の Philly のフォルダから読みます(後述)。
  ログの戦闘の数字(与えたダメージ・受けたダメージ・回復量)は、対象の
  キャラの頭に少し重なるところから浮かべて消します。ダメージを受けた
  キャラは短く点滅し、自分が受けた時は地図が少し揺れます。物理攻撃
  には対象の向きへ風切りのような斬撃の軌跡が走り、詠唱の後の攻撃
  には術師から対象へ尾を引く魔法弾が飛んで、着弾で閃光と火花が
  散ります。敵やキャラが倒れた時は、その場に残像が残ってゆっくり
  消えます。発言(talk)と priv、NPCの発言や
  action、大声なども、話し手の頭の上に吹き出しで出ます。
- **行単位のクライアント**(`neophi.cli`):curses が使えない環境でも動く。
  受信した出来事をそのまま出し、打った行をそのまま送る。
- **プロトコル層**(`neophi` パッケージ):TCP・cp932・行分割・受信行の
  解析・ログイン・自動応答・キープアライブ。I/O を持たない部分は
  `codec` / `line_buffer` / `parser` に分かれていて、wphi の
  `crates/phi-proto` に対応する。
- **グラフィックス層**(`bmp` / `assets` / `map_graphics` / `png`):
  BMP の読み込みと透過、Philly のフォルダからの絵の探索、地図の描画、
  PNG の書き出し。wphi の `assets.rs` / `mapRender.ts` / `drawMap.ts`
  に対応する。
- **モックサーバ**(`tools/mock_server.py`):実サーバが無くても動作確認ができる。

Python 3.11 以上が必要です。依存する外部パッケージはありません。

## まずモックサーバで試す

2つの端末を使います。

```sh
# 端末1: モックサーバを立てる
cd neophi
python tools/mock_server.py --port 21000
```

```sh
# 端末2: TUI クライアントで繋ぐ
cd neophi
PHI_ID=TESTID python -m neophi.tui --host 127.0.0.1 --port 21000
```

TUI では、矢印キーで移動し、`Tab` で入力欄へ移って発言できます。
`Ctrl+Q` で終わります。行単位のクライアントで試す時は、`-m neophi.cli`
に置き換え、`go N` のように打って移動し、`/quit` で終わります。

GUI クライアントで試す時は、こうします。`--assets-dir` には、Philly の
フォルダ(中身が `chara/` や `Skins/` のフォルダ)を指定します。wphi の
リポジトリを持っている時は、その中の `resources/phi` でも動きます。
指定しなければ、絵の代わりに色で塗った地図になります。

```sh
# 端末2: GUI クライアントで繋ぐ
PHI_ID=TESTID python -m neophi.gui --host 127.0.0.1 --port 21000 \
  --assets-dir /path/to/Philly
```

数字の浮かび方と吹き出し、戦闘の演出を試す時は、`--float-demo` を付けると、
戦闘のログと発言を定期的に出して、地図のキャラの頭に数字が浮かび、
吹き出しが出て、剣の軌跡や魔法弾が出ます。

```sh
# 数字の浮かび方を試す
PHI_ID=TESTID python -m neophi.gui --host 127.0.0.1 --port 21000 \
  --assets-dir /path/to/Philly --float-demo
```

ログの文面の型は `neophi/float_text.py` の表にあります。実サーバ
(rel5g MasterGate) のメッセージ集 `dm_msg_jp.h` の文面に合わせてあり、
攻撃・罠・暴発・治療・吸収・食べ物の数字を読みます。MP のダメージは
青い数字で出ます。

GUI では、地図をクリックしても移動できます(左が移動、右が攻撃)。
`拡大` のボタンで地図を 1〜3倍にできます。`Ctrl+Q` で終わります。
EagleEye を唱えると、別の窓に広い地図が出ます。

地図の見方は、`表示` のボタンか `/view` の命令で切り替えられます。
平面のほか、擬似3Dのクオータービューが3つあります。床を斜めに潰し、
壁の高さとキャラを立てて描く、試しの表示です。

- `傾け`:床を縦に半分に潰す見方。
- `斜め`:斜め45度にずらす見方。
- `立体`:ダイヤ型の見方。

起動時に `--view oblique` のように指定もできます。クオータービューの
地図のクリックでも、指したマスの方向へ移動できます。

地図の描画だけを確かめたい時は、GUI を開かずに PNG にできます。

```sh
python tools/render_map.py --assets-dir /path/to/Philly --out-dir /tmp/maps
# 平面と3つのクオータービューを比べる1枚も作れます
python tools/render_quarter.py --assets-dir /path/to/Philly --out-dir /tmp/quarter
# --v X,Y で、自分で写し方を試すこともできます
python tools/render_depth.py --assets-dir /path/to/Philly --out-dir /tmp/depth
# 床を歪ませず、高さの引き伸ばしと影だけで立体感を出す試しも比べられます
python tools/render_3d.py --assets-dir /path/to/Philly --out-dir /tmp/3d --turntable 8
# 3Dの試作。絵の輪郭を立体物に押し出して描きます。1枚0.3秒ほどで、
# 静止画専用です。--style boxes で、箱に絵を貼る描き方も比べられます
```

モックサーバは、移動・リスト(`get` / `cast`)・看板(`write` / `read`)・
EagleEye(`cast` の後に `eagle eye`)の返事をします。看板の本文にはわざと
`#ch-srv` や `#x` の行が入れてあり、`#more` の間はコマンドとして実行しない
事も確かめられます。

## 実サーバへ繋ぐ

接続先は、Philly / wphi の `worlds.ini` にある世界のホストとポートを使います。
キャラIDは、次の3通りのどれかで渡します。

```sh
# 1. 引数で渡す(シェルの履歴に残るので注意)
python -m neophi.tui --host <ホスト> --port <ポート> --id <キャラID>

# 2. 環境変数で渡す
PHI_ID=<キャラID> python -m neophi.tui --host <ホスト> --port <ポート>

# 3. 省略すると、入力を求められます(打った文字は表示されません)
python -m neophi.tui --host <ホスト> --port <ポート>
```

キャラIDは認証そのものです。このクライアントは ID をファイルに保存しません。
`--record-dir` を指定すると受信した生のバイト列を残せますが、送った行は
残らないので ID は含まれません。それでも、記録には他のプレイヤーの発言が
入るので、共有する時は中身を確かめてください。

## 配布用パッケージ

Windows 用と macOS 用の2通りの配り方を用意しています。

### 1. `neophi.pyz`(Python が入っていれば動く)

Python 3.11+ と Tkinter が入った環境なら、そのまま動きます。

```sh
# macOS / Linux
python3 neophi.pyz gui --host <ホスト> --port <ポート>

# Windows (python.org 版の Python)
py neophi.pyz gui --host <ホスト> --port <ポート>
```

`gui` の代わりに `tui`・`cli` も使えます。グラフィックスは、利用者の
Philly フォルダから読むので、別途 `--assets-dir` で指定してください(後述)。

### 2. スタンドアロン(.exe / .app、Python 不要)

PyInstaller で固めたもので、Python の入っていない環境でも動きます。
PyInstaller はクロスコンパイルできないので、それぞれの OS でビルドします。

```sh
# macOS で NeoPHI.app を作る
sh packaging/build-macos.sh

# Windows で NeoPHI.exe を作る(コマンドプロンプトで)
packaging\build-windows.bat
```

macOS 版は署名なしビルドなので、初回は右クリック→「開く」で起動して
ください。アイコンやバンドル ID を変えたい時は
`packaging/neophi-gui.spec` を直してください。

## TUI の操作

Philly のキー操作です。キーは、入力欄の外にいる時(操作モード)だけ操作に
なります。

| 状態 | キー | すること |
|---|---|---|
| 操作 | 矢印キー / テンキー | 移動・向きを変える(北固定と回転で意味が変わる) |
| 操作 | `Z` `X` `C` `V` `F` `A` `S` `D` `B` `Q` `W` `R` `M` `H` `N` `Y` | 拾う・置く・使う・並べ替え・床の品・読む・書く・消す・掲示板・装備・外す・魔法一覧・調べる・挨拶・n・y |
| 操作 | `Space` | 攻撃 |
| 操作 | `T` / `Shift+T` | 地図を回転 / 北固定にする |
| 操作 | `Shift+7` / `Shift+5` | 地図を 7x7 / 5x5 にする |
| 操作 | `Tab` | 入力欄へ |
| 操作 | `PgUp` / `PgDn` | ログをさかのぼる / 戻る |
| 操作 | `Esc` | さかのぼりをやめる |
| 操作 | `Alt+文字` | 系統魔法(`Alt+W` は wizard eye など)。`Alt+B` と `Alt+R` は確かめてから送る |
| 操作 | `Ctrl+Q` | 終わる(`#x` を送って切断) |
| 入力 | `Enter` | 送る |
| 入力 | `Esc` | 操作モードへ |
| 入力 | `↑` `↓` | 入力の履歴 |
| 入力 | `/help` などの `/` で始まる行 | クライアント内の命令(一覧は `/help`) |
| リスト | `1`〜`9` | 選ぶ。`9` は続きのページ |
| リスト | `Space` / `Enter` | チェックを付ける / チェックしたものを送る |
| リスト | `↑` `↓` | カーソルを動かす |
| リスト | `.` / `Esc` | 取り消し |
| リスト | `-` | すべて |
| 看板 | 本文を打って `Enter` | 次の行へ。`.` だけの行で終わり、`.!` で取り消し |

フルキー移動は on です。`I` はテンキーの5、`J` `K` `L` `U` `O` は
テンキーの1〜6として扱います。

## 系統魔法の前の自動装備外し

Philly と同じく、系統魔法を唱える前に武器を外します(仕様書 §7.1、
Philly の AutoUnequipSystemMagic、既定 on)。`Alt+W` などで唱えると、
クライアントが `unequip` だけを先に送り、装備のリストを見て1番が武器なら
`1` を、防具か装身具なら `.` を送ってから唱えます。装備のリストと
「外す装備を選択して下さい」は画面に出ません。何も装備していなければ
そのまま唱えます。唱える行は5秒で忘れます。

唱えた後に武器を装備し直すのは、既定ではしません(Philly の
AutoEquipSystemMagic、既定 off)。装備し直す時は `--auto-equip` を付けて
ください。外さないで唱えたい時は `--no-auto-unequip` を付けます。
TUI と GUI の両方で同じです。

## v1 で出来ることと、まだ無いもの

出来ること:接続・ログイン・ログと発言の表示・状態と状態異常の表示・
7x7 / 5x5 の文字の地図・BMP の絵の地図(GUI)・移動と行動のキー・
マウスでの移動・リストの選択・看板の読み書き・系統魔法のキー・
系統魔法の前の自動装備外し(既定 on)・
EagleEye の文字の図と絵の図・キープアライブと自動応答・
`#more` の間の安全な扱い・世界移動(違うホストへ移る時は確認します)。

まだ無いもの(次の段階で作る):

- **priv の画面**:受信した priv はログに出ます。`priv` の送信は、入力欄から
  `priv <番号> 本文` の形で直接打つ事ができます。宛先の番号は `/ulist` で
  確かめられます。
- **地図の細かい表示**:拡大表示は描いた絵をそのまま大きくするだけで、
  チップの種類ごとの合成(タイル敷きなど)はまだありません。滑らかに
  ずらす移動、記録地図(automap)、方角の絵の表示、スキンのマウス
  カーソルもまだありません。クオータービューは試しの表示で、EagleEye
  の窓は今も平面のままです。3Dレンダラも試作で、GUI には繋がって
  いません。壁や家は扉と同じ高さの箱、木は輪郭を押し出した十字の
  立体物、扉は板一枚(扉のマスの床は地面の絵)、閉じた宝箱は上の蓋が
  開いた形、開いている箱は実際の開口のある箱形、岩は上へすぼまる
  岩形、看板は板の立体物、アイテムは床の浮き彫りとして作り直して
  います。キャラは元の絵をカメラへ向けた板のままです。
- **超魔法のメニュー・音・スキン・複数タブ・キャラの登録と管理・設定ファイル**:
  まだありません。

## セキュリティの注意

- キャラIDは、そのまま認証に使えます。ファイルに残さず、他の人に見せない
  でください。`--id` で渡すとシェルの履歴に残ります。
- 世界移動の要求(`#ch-srv`)は、悪意のあるサーバが任意のホストへ ID を
  送らせるために使えるものです。今と違うホストへ移る時は、`#reserve`
  で ID を送る前に必ず確かめます(GUI ではダイアログ、TUI では y/n、
  行単位では y/n の行)。断るか、5分答えなければ留まります。
- 看板などの本文(`#more` 〜 `#end-more`)に書かれた `#` の行は、コマンド
  として実行しません。モックサーバの `read` で確かめられます。
- 発言タグの画像は、文字として出すだけで取得しません。受けた人の環境から
  LAN の機器へ要求を出させる事がありません。
- 地図の絵は、利用者の Philly のフォルダからだけ読みます。キャラ名や
  グラ名でフォルダの外を指すパスは読みません。LANU 系のグラフィックスは
  使いません(wphi と同じ扱いです)。

## 開発

テストは標準の `unittest` だけです。

```sh
cd neophi
python -m unittest discover -s tests
```

`tests/test_parser_golden.py` は、wphi の golden データ
(`crates/phi-proto/tests/golden/parser.json`、103ステップ)とパーサの出力を
比べます。このデータは phi-client-web の Python パーサの出力を正解として
作られたもので、MIT ライセンスの wphi リポジトリから写しました。

受信の生のバイト列を残したい時は、`--record-dir` を付けます。wphi の
`WPHI_RECORD` と同じ考え方です。
