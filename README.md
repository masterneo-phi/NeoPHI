# NeoPHI

PHI オンラインゲーム用の新しいクライアントです。Godot 版をメインに、Python 版を参照実装として開発しています。

## フォルダ

- `godot/` — Godot 4.7 版クライアント（メイン）。Godot でプロジェクトを開いて実行できます。詳しくは `godot/README.md` を参照してください。
- `python/` — Python 版クライアント（参照実装）。標準ライブラリのみで動きます。詳しくは `python/README.md` を参照してください。

## グラフィックスについて

このリポジトリにはゲームのグラフィックス（BMP・MIDI など）を含みません。クライアントは実行時に、利用者の Philly / wphi フォルダからグラフィックスを読み込みます。
