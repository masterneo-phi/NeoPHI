# NeoPHI Godot 版試作

PHI ゲームのクライアント「NeoPHI」を Godot 4 で作れるか確かめるための試作です。
正解の参照実装は Python 版（`~/workspace/phi-client-py/`）で、通信・パーサ・
地図の配置ルールはそこから GDScript へ移植しています。

## はじめて動かすとき（動かない場合の確認）

動かすには、次の3つが必要です。

1. **Godot 4.7.2 のエディタ**（このプロジェクトは 4.7 用です。古い
   バージョンでは開けないことがあります）
2. **接続先のサーバ**（既定は自分の PC の 127.0.0.1:20017 です。サーバが
   動いていないと、ログ欄に接続エラーが出て地図は出ません。試作の確認には
   Python 版のモックサーバ `tools/mock_server.py` も使えます）
3. **グラフィックスのフォルダ**（既定の場所は作者の環境のものです。自分の
   環境では、素材集のフォルダを `--chip-dir` と `--chara-dir` で指定するか、
   Philly フォルダを `--assets-dir` で指定してください。エディタから実行
   する時は「実行 > 実行構成」やプロジェクト設定の「実行時引数」に書きます。
   フォルダが見つからないと、キャラは黄色い四角になります）

## 動かし方

Godot 4.7.2 のエディタでこのフォルダをプロジェクトとして開き、実行します。
コマンドラインから動かす場合:

```
godot --path . -- --host 127.0.0.1 --port 20017 --id guest
```

引数は `--` の後に書きます。

| 引数 | 既定値 | 意味 |
|---|---|---|
| `--host` | 127.0.0.1 | 接続先ホスト |
| `--port` | 20017 | 接続先ポート |
| `--id` | guest | キャラクタID |
| `--chip-dir` | （自動探索） | マップチップBMPのフォルダ |
| `--chara-dir` | （自動探索） | キャラBMPのフォルダ（カンマ区切りで複数可） |

指定が無い時は、実行ファイルのあるフォルダ直下 → macOS の .app の入った
フォルダ直下 → カレントディレクトリ直下 → 開発用の
`~/workspace/phi-option-data` の順に `chip_tofup` / `chara_tofup` を探します。
見つからない場合はログ欄に警告が1行出ます。
| `--assets-dir` | なし | Philly 式フォルダ（`chara/` や `Skins/` を持つもの。種族既定グラの解決に使う） |
| `--skin` | Mine | Philly 式フォルダで使うスキン名 |
| `--default-chara` | なし | フラット式で、見つからないキャラの代わりに使うBMP名 |
| `--items` | なし | アイテムBMP（`Items.bmp`）の場所 |
| `--shot <path>` | なし | 指定秒後に画面をPNGで保存して終了する |
| `--shot-delay <秒>` | 0 | `--shot` の待ち時間 |
| `--keytest <キー>` | なし | テスト用。カンマ区切りのキーを押されたものとして流し込む（`Down,Tab,type:hello,Enter` など） |
| `--fx-demo` | なし | 試し表示。攻撃・回復・発言・詠唱＋魔法攻撃・死亡の行を合成して定期的に流し、エフェクトを出します（モックサーバは戦闘ログを出さないため）。通常のプレイには影響しません |
| `--config <パス>` | `user://NeoPHI.ini` | 設定ファイルの場所 |
| `--no-config` | なし | 設定ファイルを読まず、保存もしません |
| `--map-size <40\|57>` | 設定値 | 地図の大きさ（40=5x5、57=7x7）。設定より優先します |
| `--map-style <solid\|turn>` | 設定値 | 地図の向き（solid=北固定、turn=回転）。設定より優先します |

ウィンドウは 1280x1024、レンダラーは Mobile です（macOS では Metal、
Windows では Vulkan 経由になります）。以前の Compatibility（OpenGL）
では、macOS で窓を縦に大きくすると Godot の描画部分で落ちることが
あったため、Mobile に変えています。念のため、窓の大きさの上限
（全画面のうち最大のもの）も残しています。ウィンドウの大きさを変えると、
地図も整数倍で追従します。

## 設定の保存

接続先・スキン名・ウィンドウの大きさ・分割位置・地図の大きさと向き・
ログスクロール停止を、Philly.ini 互換のセクション名で
`user://NeoPHI.ini` に保存します（`[Connection]` `[Skin]` `[Map]`
`[Disp]` `[Log]`）。第2段で、F1〜F7 の魔法名と F8〜F12 の自由
ショートカット・Alt+G の言葉（`[Shortcut]`）、行頭 `*` の扱いと
Ctrl+Enter のパーティー発言（`[Edit]`）、priv ウィンドウの自動表示
（`[Priv]`）も同じファイルに保存します。起動時に読み、終了時と設定の変更時（地図モードの
切り替え、ログスクロール停止の切り替え）に保存します。コマンドライン
引数は設定より優先します。キャラクタIDは保存しません
（`--id` か既定の `guest` を使います）。

## 操作方法

- **矢印キー / テンキー**: 移動（Philly の移動キー表に従います）。
  北固定地図（7x7・solid）の時は絶対方向（`go N` など）、回転地図の
  時は相対移動（`go`・`go l`・`go r`）になります。キーを押し続けると
  歩き続けます（地図の到着に合わせて次の一歩を送ります）。
  **Ctrl+矢印キー / Ctrl+テンキー**は、向きを変えずにその方向へ
  進むカニ歩き（`go n` など）です。回転地図では左右キーがカニ歩き
  になります。
- **F1〜F7**: 呪文を唱えます（`cast` + 番号）。設定で魔法名を入れて
  「魔法名で送る」を on にすると、番号ではなく名前で送ります。
  唱えた後の魔法リストは表示しません（Philly の NextListCancel）。
- **F8〜F12**: 自由ショートカット。ツールメニューの「ショートカット
  設定」で任意の文字列を割り当てられます（`\n` で改行）。
  リストが出ている間は、リスト用の文字列を送ります。
- **Tab**: 入力欄へのフォーカスを切り替え
- **Esc**: 入力欄からフォーカスを外して移動キーに戻る。リストが
  出ている時はリストを取り消します（`.` を送ります）。
- **Enter**（入力欄にフォーカスがある時）: 入力した行を送信
- **Shift+Enter**（入力欄にフォーカスがある時）: 改行を入れる
- **Ctrl+Enter**（入力欄にフォーカスがある時）: パーティー発言
  （行頭に `+` を付けます）
- **Alt+G**: あいさつの言葉（既定は「おやすみなさいませ」）を発言します
- **大声ボタン**（ツールバーと操作メニュー）: on の間は入力欄が
  黄色くなり、送信時に確認ダイアログが出ます。「はい」で大声
  （行頭に `*`）を送ってボタンを off に、「すべて大声」で確認なしの
  大声が続きます。
- **Shift+F6** / 操作メニューの「新規プリブウィンドウ」: priv
  ウィンドウを開きます。宛先にチェックを入れて言葉を送ると、
  `priv <番号> <言葉>` を宛先ごとに送ります。priv を受けると
  履歴に残り、設定が on ならウィンドウも自動で出ます。
- **リストの表示**: `#list` が来ると、地図の上に重ねて表示します
  （ログへの表示も残します）。数字キー・上下キーと Enter・
  ダブルクリック・決定/キャンセルボタンで選んで送信できます。
  `0`・`.`・左右キーは取り消し、`-` は全部を送ります。
- **メニューバー**（ファイル/操作/行動/魔法/表示/ツール）と**ツールバー**:
  Philly の操作をボタンとメニューから送ります。スキンの
  `Style/Menu.txt` で `off` のメニューは表示しません。
- **地図とログの境目をドラッグ**: 地図とログの幅を変えます。
  初期状態は地図 55%・ログ 45% で、ログの最小幅は 280px です。
  分割位置は設定ファイルに保存されます。

入力欄は常時3行分以上の高さがあります。入力欄にフォーカスがある間は、
矢印キーは文字カーソルの移動になります。
ログ・入力欄・状態行の文字サイズは、地図の倍率に比例します（8 × 倍率）。
ウィンドウを大きくすると地図の倍率と一緒に文字も大きくなります。
日本語入力は OS の IME に任せています（実機での確認は未済です）。

## グラフィックスの指定方法

グラフィックスはプロジェクトに同梱しません。実行時にフォルダから読みます。

- **フラット式**（素材集 `phi-option-data/` の形）: `--chip-dir` と
  `--chara-dir` でフォルダを指定します。チップは `<マップセット名>.bmp`、
  無ければ `default.bmp` を使います。キャラは `<名前>.bmp` を探します
  （大文字小文字は区別しません）。
- **Philly 式**（Philly フォルダや wphi の `resources/phi` の形）:
  `--assets-dir` でフォルダを指定します。指定が無くても、
  グラフィックスと同じ順序（実行ファイルのあるフォルダ直下→
  .app の入ったフォルダ直下→カレントディレクトリ直下→開発用
  フォルダ）で `Skins/<スキン名>/` を含むフォルダを自動で探し、
  見つかればスキンとして使います。スキン名は設定の SkinName
  （既定 `Mine`）です。見つからない場合は警告を1行だけ出し、
  文字ボタンで従来どおり動きます。`chara/*.ali` の別名、
  `Skins/<スキン>/Chara/Index.txt` の種族既定グラ、`chip/<マップセット>.bmp`、
  `Skins/<スキン>/Images/Items.bmp` のほか、スキンの
  `Buttons/Index.txt`（ツールバーとメニューのアイコン、20x20、
  Teal色が透明）、`Images/*.bmp`、`Cursor/*.cur`、
  `Style/Log.css`（ログの背景色・文字色とシステム行の色）、
  `Style/Menu.txt`（メニューの表示/非表示）を読みます。
- 両方を指定すると、フラット式を先に探し、無ければ Philly 式を探します。
  種族既定グラ（`#m57 O` の種別から決まる絵）は Philly 式の `Index.txt`
  が無いと解決できないため、その場合は黄色い代替表示になります。
- `lanu_` で始まるファイルは読みません（作者の指定による除外）。
- 見つからないキャラは、黄色い四角と名前の頭文字で表示します。

素材集の BGM（MIDI）は `~/workspace/phi-option-data/bgm_*` にありますが、
音は試作の範囲外のため使っていません。`worlds/worlds.ini` は世界の接続先
リストですが、この試作はモックサーバとローカルのテストサーバにだけ接続し、
外部サーバには接続しません。

## 実装済み

- **cp932 変換**（`scripts/cp932.gd` + `cp932_table.json`）:
  Python の `cp932` コーデックから生成した全対応表で、復号・符号化の両方向。
  半角カナを含みます。検証結果は下の「検証」を見てください。
- **TCP 接続とログイン**（`scripts/phi_session.gd`）: `StreamPeerTCP`、
  Python 版と同じログイン行、キープアライブ（2分無受信で `#code-sjis`）、
  `#lag`→`#end-lag`・`#remap`→`#map` の自動返信。
- **パーサ**（`scripts/phi_parser.gd`）: Python 版 `parser.py` の忠実な移植。
  `#m57` / `#map` / `#ex-eagleeye` のバイナリ行を含みます。
- **地図の描画**（`scripts/map_view.gd` + `scripts/bmp_loader.gd` +
  `scripts/game_assets.gd`）: 7x7 の地図を BMP で2D描画。32pxセル、
  チップ48px、マップ上部16px、キャラの足位置、同セル2人のずらし、
  名前表示、水の継ぎ目、看板・アイテムの重ね描きまで Python 版と同じ規則。
- **移動と入力**: 矢印キー・テンキー・Philly の移動キー、入力欄からの送信。
- **画面**: 地図＋ログ＋入力欄＋状態表示（名前・HP/MP・Exp・GP・世界名・
  エリア名・接続先）。
- **タグの除去**（`scripts/phi_tags.gd`）: ログ行の `/*...*/` を取り除いて表示。
- **戦闘演出**（`scripts/float_text.gd`・`scripts/bubbles.gd`・
  `scripts/combat_fx.gd` + `map_view.gd`）: Python 版と同じ見た目で、
  浮き数字（与えた黄・受けた赤・回復緑・MP青）、対象キャラの点滅、
  自分が受けた時の地図の揺れ、斬撃の軌跡、魔法弾と着弾、倒れた残像、
  発言・NPC の吹き出しを出します。大きさは地図の倍率に連動します。
  テストは `tests/test_fx.gd`（265件）。
- **設定の永続化**（`scripts/phi_config.gd`）: 上の「設定の保存」を参照。
- **スキン読み込み拡張**（`scripts/skin_files.gd` +
  `scripts/game_assets.gd`）: Philly の Skins 構造（Buttons/Images/
  Cursor/Style/chara）を読みます。テキストは UTF-8 か cp932 かを
  中身で判定します。カーソルは `.cur`（DIB マスク付き・PNG埋め込み）
  を復号します。
- **ツールバーとメニュー**（`scripts/phi_actions.gd` + `main.gd`）:
  Philly の `Command.cpp` の操作表を移植。送信・入力ダイアログ
  （支払い・看板検索・出現/消去）・接続/切断・終了・設定の読み込み/
  初期化・グラキャッシュ初期化・スクリーンショット・ログスクロール
  停止・設定フォルダを開く・バージョン情報。接続状態で使えない
  項目は無効化します。隠しコマンドの自動戦闘系は含みません。
- **地図とログの分割**（`main.gd`）: ドラッグで幅を変えられる
  HSplitContainer。初期状態は地図 55%・ログ 45%。
- **地図の倍率**（`scripts/map_view.gd`）: 割り当てサイズに収まる
  最大の整数倍率。拡大は1段階ずつ、縦にだけ 96px の余裕を要求する
  ヒステリシスがあります（文字サイズ連動で行の高さが増えるため、
  ぎりぎりで拡大すると拡大と縮小を繰り返して収束しません。横は
  文字サイズに影響されないので、幅の余裕は要求しません）。
- **第2段・操作系**（`scripts/phi_shortcuts.gd` + `main.gd`）:
  F1〜F7 の呪文ショートカット（番号/魔法名の2方式と、次のリストの
  抑え込み）、F8〜F12 の自由ショートカット（設定ダイアログ付き、
  リスト用の文字列も別に持てます）、押し続け移動（地図の到着に
  合わせて次の一歩を送り、地図が来ない場所では 500ms ごとに送る。
  サーバの処理速度に合わせて 120ms の最小間隔を空けます）と
  カニ歩き（Ctrl+移動キーで向きを変えずに進みます）、大声ボタンと
  確認ダイアログ（はい/いいえ/すべて大声、入力欄の黄色表示）、
  パーティー発言（Ctrl+Enter）、Alt+G のあいさつ、priv ウィンドウ
  （宛先チェック・履歴・送信・リスト更新・受信時の自動表示）、
  リストのオーバーレイ表示（地図の上に重ね、数字キー・上下キーと
  Enter・ダブルクリック・ボタンで選択。ログへの表示も残します）。
  移動キー表は地図の大きさと様式で切り替わります（7x7・solid なら
  北固定表、それ以外は回転表）。リストの複数チェック・ページ送り・
  書き出しと、同時押しの斜め移動は後回しです（理由は調査書の
  第2段の節と、この README の「未実装」を参照）。

## 検証

- **cp932**: 復号 15,822 件（全1バイト、全先行バイト×全2バイト目、
  乱数列200本、実際のゲーム行）、符号化 63,495 件（BMP 全符号点と
  日本語文）を Python のコーデックと照合。NUL バイトを含む場合を除き
  完全一致。NUL は Godot の String が保持できないため、その位置で
  文字列が切れます（実際の通信では現れません）。符号化の不一致は
  U+0000 と U+FEFF の2件のみで、どちらも Godot の String に
  入らない文字です。生成スクリプトは `tools/gen_cp932_table.py`、
  テストは `tests/test_cp932.gd`（`godot --headless --path . -s tests/test_cp932.gd`）。
- **パーサ**: wphi の golden データ（`tests/fixtures/parser.json`、12シナリオ
  103ステップ）と全一致。`tests/test_parser.gd` で再現できます。
- **モックサーバ**: ログイン→地図表示→移動（地図がスクロールすること）→
  入力欄からの送信（返事がログに出ること）を確認。
- **実サーバ**（127.0.0.1:20017、guest）: ログイン・状態・7x7地図・移動・
  ログを確認。種族既定グラは `--assets-dir` に Philly 式フォルダを
  渡すと解決されます。
- **第1段**（設定・スキン・ツールバー/メニュー・分割）:
  `tests/test_stage1.gd`（939件）で、設定の保存と読み込み・スキン
  ファイルの解析・実 Philly ファイル（Mine）・操作表・ズームの
  ヒステリシスを確かめています。画面では、実スキンでのアイコンと
  白ログ、`Menu.txt` の `off` での非表示、メニューの展開、入力
  ダイアログ、分割の初期位置（地図 55%・ログ 45%）、設定の往復
  （保存→再起動→復元、CLI 上書き、`--no-config`）をモック相手に
  確認しました。1700x1300 でのズーム反転はヒステリシスで解消し、
  収束することを計測で確認しています。
- **第2段**（操作系: F1〜F12・繰り返し移動・大声・priv・リスト）:
  `tests/test_stage2.gd`（156件）で、ショートカットの変換・発言の
  変換・設定の新しいキー・スキン探索・操作表の追加項目・移動キー表
  を確かめています。画面では、モック相手に、スキンの自動探索
  （`--assets-dir` 無しで Mine のアイコンが出ること）、リストの
  オーバーレイ表示と数字キーでの選択、priv ウィンドウの表示と
  受信時の自動表示、ショートカット設定ダイアログ、大声の確認
  ダイアログ（はい/いいえ/すべて大声）、F1 のリスト抑え込み、
  Alt+G の発言、繰り返し移動（2秒の長押しで4歩進み、離すと止まる
  こと）、カニ歩き（Ctrl+左で向きが変わらず、左で西を向くこと）、
  Space の長押しが1回だけの攻撃になることを、スクリプトによる
  26件の実機チェックで確認しました。

## つまずいた点（移植メモ）

- GDScript の `var x := <Variantを返す関数>` は、この環境では警告ではなく
  コンパイルエラーになります。`-> Variant` な関数の受け取り側は
  `var x: Variant = ...` と明示する必要があります。
- `"\0"` は GDScript の文字列リテラルに書けません。NUL の検査は
  `unicode_at` で行っています。
- キー処理は `_unhandled_key_input` ではなく `_input` で受ける必要があります。
  `_unhandled_key_input` だと、矢印キーや Tab が GUI のフォーカス移動に
  奪われて届きません。ログ表示は `focus_mode = FOCUS_NONE` にしています。
- `_input` という関数名は、同名のメンバ変数と衝突してコンパイルエラーに
  なります（変数名に注意）。
- `String.chr()` は存在します。`KEY_KP_DECIMAL` は無く、`KEY_KP_PERIOD` が
  テンキーの小数点です。
- Godot の String は NUL を保持できず、先頭の BOM を取り除きます。
  cp932 変換の差分はこの2点だけです。
- 地図の描き始めの位置（オフセット）が小数だと、チップの端が隣の
  絵と混ざってセルの境に黒い線が出ます。オフセットは整数に丸めます。
- 地図の倍率は文字サイズに連動し、文字サイズは行の高さを変え、行の
  高さは地図の割り当てを変えます。倍率の拡大に余裕を要求しないと、
  特定の窓サイズで拡大と縮小を繰り返してレイアウトが収束しません
  （1700x1300 で実測）。拡大は1段階ずつ、縦にだけ 96px の余裕を
  要求するヒステリシスで防ぎます（幅の余裕まで要求すると、縮小
  して1まで落ちたあと大きくし直しても戻らなくなります）。
- `class_name` のある新しいスクリプトは、エディタの走査
  （`godot --headless --editor --quit`）で登録しないと、他の
  スクリプトから名前で使えません。
- 地図イベントの `size` はマスの数（7 が `#ex-map size=57`、5 が
  `size=40`）です。57/40 と比べると北固定の判定が常に偽になります。
- `Window` は既定で表示される（`visible = true`）ため、作った直後に
  `add_child` すると (0,0) に最小サイズで出てしまいます。後から
  `popup_centered` で出す窓は、作る時に `visible = false` にします。
- `RichTextLabel.text` は `add_text()` で足した内容を返しません。
  表示中の全文を読むには `get_parsed_text()` を使います。
- `ConfirmationDialog` に入れる `Label` で折り返し（autowrap）を
  on にすると、高さの計算が膨らんでダイアログが画面いっぱいに
  なることがあります。改行入りの固定文は折り返しを off にし、
  幅を `custom_minimum_size` で明示します。
